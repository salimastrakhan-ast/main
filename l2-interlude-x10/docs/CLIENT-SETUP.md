# Клиент, геодата и как пустить друзей

Серверная часть готова — осталось объяснить клиенту игры, куда подключаться.

---

## 1. Клиент

Нужен клиент **Interlude (Chronicle 5, протокол 746)**. Клиенты других хроник
не подойдут: протоколы несовместимы, сервер отклонит подключение.

Клиент — твой собственный, легально полученный. Этот стенд его не содержит,
не скачивает и не распространяет.

Если стенд собирается под L2 Classic (`L2_CHRONICLE=L2J_Mobius_Classic_Interlude`),
то и клиент нужен от Classic — это другая игра с другим протоколом.

---

## 2. Куда подключается клиент

Клиент Interlude берёт адрес логин-сервера из файла `system/l2.ini`
в папке игры:

```ini
[Server]
ServerAddr=127.0.0.1
```

Замени на значение, которое стоит у тебя в `.env` как `L2_EXTERNAL_IP`.

Дальше происходит вот что, и это важно понимать для диагностики:

1. клиент подключается к **логин-серверу** (порт 2106) — авторизация;
2. логин-сервер отдаёт **список серверов** с адресами;
3. клиент подключается к **игровому серверу** по адресу из этого списка —
   а он берётся из `ipconfig.xml`, куда стенд подставляет `L2_EXTERNAL_IP`.

Отсюда самая частая ошибка новичков: логин проходит, сервер в списке виден,
но при входе в мир — вечное «Connecting...». Значит, `L2_EXTERNAL_IP`
остался `127.0.0.1`, и клиент на другом компьютере ломится сам в себя.
Лечится правкой `.env` и `make configure`.

Технически адрес задаётся не ключом в `.ini`, а файлом
`dist/game/config/ipconfig.xml` — его создаёт `make configure` из значений
`.env`. Логин-сервер сопоставляет IP подключившегося клиента с подсетями
из этого файла и отдаёт подходящий адрес. Править файл руками не нужно:
следующая пересборка его перезапишет.

## 3. Геодата

Без геодаты мобы ходят сквозь стены, стреляют через скалы, персонажа
откатывает назад при беге. Игроки называют это лагами (см.
[ANTI-LAG.md](ANTI-LAG.md)), но это именно отсутствие карты проходимости.

Геодата — производная от клиента игры и в исходный код эмулятора не входит,
поэтому файлы нужно положить самому:

```
dist/game/data/geodata/
```

Требования:

- формат должен соответствовать эмулятору (у Mobius — свой, у aCis — свой;
  файлы от другого эмулятора не подойдут);
- геодата должна быть **от той же хроники**, что и сервер.

Проверить, что подхватилась:

```bash
make logs | grep -i geo
```

В логе при старте будет число загруженных регионов. Ноль регионов —
файлы не там или не того формата.

Соответствующие настройки уже включены профилем x10:

```ini
GeoDataPath = ./data/geodata/
PathFinding = 2
```

## 4. Игра с других компьютеров

### По локальной сети

1. Узнай LAN-адрес машины с сервером (`ip a` или `ipconfig`) — что-то вида
   `192.168.1.50`.
2. В `.env`: `L2_EXTERNAL_IP=192.168.1.50`
3. `make configure && make restart`
4. На каждом клиенте в `system/l2.ini`: `ServerAddr=192.168.1.50`

### Через интернет

1. `L2_EXTERNAL_IP` — внешний IP машины или домен.
2. Пробрось порты **2106** (логин) и **7777** (игра) на машину с сервером.
3. Порт базы **3306 пробрасывать нельзя** — стенд специально публикует его
   только на `127.0.0.1`. База, торчащая в интернет, — это вопрос дней
   до взлома.
4. Открой порты в файрволе:

```bash
sudo ufw allow 2106/tcp
sudo ufw allow 7777/tcp
```

Если внешний IP динамический, бери бесплатный DDNS-домен и указывай его
в `L2_EXTERNAL_IP` — тогда при смене адреса ничего перенастраивать не придётся.

## 5. Первый вход

1. Запусти клиент, введи **любой** логин и пароль — аккаунт создастся
   автоматически (`AutoCreateAccounts = True`). Запомни их: второй раз
   те же данные будут проверяться как обычный пароль.
2. Создай персонажа.
3. Выдай себе права ГМ:

```bash
make gm CHAR=ИмяПерсонажа
```

4. Перезайди персонажем. Проверь `//admin` — откроется панель ГМ.

Когда сервер перестанет быть «для себя», выключи автосоздание аккаунтов:
в `config/profiles/_network.conf` поставь `AutoCreateAccounts = False`
и делай аккаунты осознанно.

## 6. Быстрая проверка, что всё работает

| Что | Как | Норма |
|---|---|---|
| Порты | `make status` | 2106 и 7777 слушаются |
| Сервер в списке | зайти клиентом | сервер виден, статус Online |
| Вход в мир | выбрать персонажа | загрузка без «Connecting...» |
| Геодата | агрить моба из-за стены | моб бежит в обход |
| Рейты | убить моба | опыта примерно в 10 раз больше обычного |
