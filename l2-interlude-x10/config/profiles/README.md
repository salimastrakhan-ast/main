# Профили настроек

Профиль — список «файл : ключ = значение», который применяется к конфигам
собранного сервера. Он правит только перечисленные ключи и не трогает
всё остальное.

## Зачем так, а не готовыми конфигами

Соблазнительный вариант — держать готовые `Rates.ini` и копировать их поверх
сборки. Он ломается при первом обновлении эмулятора: в новой ревизии
появляются ключи, которых в твоём файле нет, и они молча получают значения
по умолчанию. Сервер работает не так, как ты думаешь, а понять это можно
только по жалобам игроков.

Профиль решает три задачи сразу:

- **переживает обновления** — правятся ключи, а не файлы целиком;
- **не молчит** — по итогам показывает, что изменено и чего не нашлось;
- **ловит несовместимость** — обязательный ключ, которого нет в сборке,
  даёт ошибку, а не тихий пропуск.

## Формат

```ini
[game]                              # к какой части сборки: game или login

Rates.ini : RateXp = 10             # обычный ключ
Rates.ini : !RateSp = 10            # обязательный: нет в сборке -> ошибка
Rates.ini : ?RateQuestReward = 2    # необязательный: нет -> тихо пропустить
Database.ini : Password = ${DB_PASSWORD}         # подстановка из окружения
Server.ini : LoginPort = ${LOGIN_PORT:-9014}     # со значением по умолчанию
```

Имена файлов у Mobius Interlude свои, и они не совпадают с привычными
по старым сборкам L2J:

| Что настраиваем | Файл у Mobius | Часто ожидают |
|---|---|---|
| Рейты | `Rates.ini` | `Rates.ini` |
| Автолут, обучение скиллам | `Player.ini` | `Character.ini` |
| Подключение к базе | `Database.ini` | `Server.ini` |
| Порты и связка с логином | `Server.ini` | `Server.ini` |
| Пулы потоков | `Threads.ini` | `General.ini` |
| Адрес для клиента | `ipconfig.xml` | `ExternalHostname` |

Правила:

- секция `[game]` или `[login]` выбирает часть сборки; по умолчанию `[game]`;
- строки после `#` — комментарии;
- файл ищется в `config/`, а если не найден — по имени во всех подкаталогах
  `config/` (разные ревизии раскладывают файлы по-разному);
- регистр имени ключа не важен, исходное написание в файле сохраняется;
- закомментированные строки в конфигах не трогаются;
- windows-переводы строк сохраняются.

## Маркеры важности

| Маркер | Если ключа нет в сборке |
|---|---|
| `!` обязательный | ошибка, выход с кодом 1 — профиль не подходит к сборке |
| нет маркера | предупреждение в отчёте |
| `?` необязательный | тихо пропускается |

`?` нужен там, где ключ существует не во всех ревизиях. Пример — `PetXpRate`
или `RateQuestReward`: в одних ревизиях есть, в других переименованы.
Ключи, без которых сервер настроен неправильно (`RateXp`, адрес базы), помечены
`!` — если такого ключа нет, значит профиль не подходит к сборке, и об этом
лучше узнать сразу.

Отдельно про адену: у Mobius Interlude нет `RateDropAdena`. Множитель задаётся
по id предмета, адена — это id 57:

```ini
Rates.ini : DropAmountMultiplierByItemId = 57,10;6656,1;6657,1;...
```

## Как узнать правильные имена ключей

Если кажется, что настройка не применяется, посмотри, как ключ называется
в твоей сборке:

```bash
grep -rn "RateXp\|DropChance" dist/game/config/Rates.ini
grep -rln "AutoLoot" dist/game/config/
```

Найденное имя впиши в профиль. Проверить, что применилось:

```bash
./scripts/configure.sh --dry-run
```

## Имеющиеся профили

| Профиль | Назначение |
|---|---|
| `x10-classic.conf` | рейты x10 в классическом духе, механики ретейл |
| `retail-x1.conf` | эталон x1 — для проверки «баг сборки или рейты?» |
| `_network.conf` | сеть и база, значения из `.env`; применяется всегда последним |

Имена, начинающиеся с `_`, — служебные, они не показываются в списке
доступных профилей.

## Свой профиль

```bash
cp config/profiles/x10-classic.conf config/profiles/my-server.conf
# правишь
./scripts/configure.sh --profile my-server
```

Чтобы он применялся по умолчанию, укажи в `.env`:

```ini
L2_PROFILE=my-server
```

## Резервные копии

Перед первой правкой каждого файла рядом создаётся `.orig` с исходным
содержимым. Посмотреть, что именно изменил профиль:

```bash
diff dist/game/config/Rates.ini.orig dist/game/config/Rates.ini
```
