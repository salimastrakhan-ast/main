## Закрыто: 3 критичных

**C1 · XSS в админке → захват аккаунта администратора.**
Добавлена `esc()`, через неё проходит каждая подстановка в `cardHtml`,
`tripCard`, `renderDrivers`, `renderTariffs`. Скрипт вынесен из `index.html`
в `src/admin/admin.js`, поэтому CSP ужат с `default-src ... *` до
`script-src 'self'`; все `onclick` заменены делегированием по `data-action`.
Токен админки переехал из `localStorage` в `httpOnly`-куку (`SameSite=Strict`),
картинки грузятся `fetch`'ем с заголовком и показываются через `blob:` —
`?token=` из URL исчез.

**C2 · Сервер стартовал с зашитым JWT-секретом.**
Фолбэк `'dev-secret-change-me'` убран: без `JWT_SECRET` или с секретом короче
32 символов процесс не поднимается. Деплой проверяет переменную **до**
перезапуска PM2, чтобы не уронить работающий сервис. Есть регрессионный тест
на реальный запуск процесса.

**C3 · Любой клиент видел GPS любого водителя.**
`watch:driver` проверяет права так же, как соседний `join:order`: подписка
разрешена только при активном заказе с этим водителем (водителю — только на
себя). При терминальном статусе заказа подписка снимается автоматически.

## Что нужно сделать руками при выкатке

**1. Миграции.** `npm run migrate` теперь версионированный: `schema.sql` —
только DDL, шаги лежат в `src/db/migrations/`, журнал — в таблице
`schema_migrations`. Прогнать **до** раскатки нового бэкенда.

**2. `JWT_SECRET` стал обязательным.** Если он не задан или короче 32
символов, сервер не стартует, а деплой останавливается до перезапуска PM2.
Проверьте `.env` на сервере заранее: `openssl rand -hex 32`.

**3. Сессии админки сбросятся.** Токен переехал в `httpOnly`-куку — админу
нужно войти заново. Учтите: кука ставится с `Secure` при `NODE_ENV=production`,
то есть админка должна открываться по HTTPS.

**4. `ALLOW_QUERY_TOKEN=true` — временно, на один релиз.** Сервер больше не
принимает токен в query-строке, а приложение до этой версии грузило так все
картинки. Бэкенд выкатывается за минуту, APK доезжает до устройств часами —
без послабления у всех, кто не обновился, пропали бы аватары, документы и
фото эвакуаторов.

Пока флаг включён, query-токен принимается **только** для `GET /api/files/*`;
на остальные эндпоинты послабление не распространяется, это покрыто тестом.
Сервер пишет предупреждение в лог при каждом старте, пока флаг активен.

**Выключить, когда обновление разойдётся по устройствам:**

```bash
# на сервере
sed -i 's/^ALLOW_QUERY_TOKEN=.*/ALLOW_QUERY_TOKEN=false/' .env
pm2 restart depanini
```

Значение читается на каждый запрос, правок кода не нужно. Пока не выключено,
токен продолжает оседать в access-логах nginx на каждый просмотр документа —
это ровно та проблема, ради которой правка и делалась.

**5. `CORS_ORIGINS=*` в `.env.example` заменён на конкретный домен.**
Проверьте, что на сервере задано реальное значение.

**6. Новые зависимости приложения:** `expo-task-manager`, `expo-updates`,
`@expo-google-fonts/cairo`. Нужен `npm install` и новая нативная сборка —
фоновая геолокация требует изменений в манифестах, через OTA не приедет.

## Что осталось за пределами правок

- **Свой OSRM с картой Алжира.** Это разворачивание контейнера, а не правка
  кода. Пока не сделано — следите за `routing.fallbackRate` в `/admin/stats`:
  доля выше 5% означает, что заказы считаются по прямой и цена занижена.
- **S3 вместо локального диска (M15).** Файлы по-прежнему лежат рядом с кодом
  на одном инстансе. Переменные в `.env.example` заведены, но переключение
  требует миграции существующих файлов.
- **Sentry (L8).** Сделан локальный журнал ошибок как минимум; внешняя
  отчётность — отдельная задача с ключами и настройкой.
- **`google-services.json` нужно перевыпустить.** В закоммиченном файле
  массив `oauth_client` пуст — вход через Google на Android не заработает,
  пока в Firebase не добавлен SHA-1 отпечаток ключа подписи. Порядок описан
  в README приложения.
- **Серверная диспетчеризация (M9).** Перебор водителей защищён от гонки на
  клиенте, но сама логика по-прежнему живёт в приложении. Перенос на сервер —
  это изменение модели заказа, отдельная задача.
