# Как применить исправления

В файле `khadamni-fixes.patch` — три коммита к репозиторию
`salimastrakhan-ast/khedma`, базовый коммит `1d95107`.

Патч отдан файлом, потому что доступ на запись к `khedma` в этой сессии не
выдавался: я мог только читать. Проверено, что патч применяется чисто на
`1d95107`.

## Применение

```bash
git clone https://github.com/salimastrakhan-ast/khedma
cd khedma
git checkout -b claude/khadamni-fixes 1d95107
git am ../khadamni-fixes.patch      # сохраняет три отдельных коммита
```

Если история уже ушла вперёд от `1d95107`, применяйте одним диффом и
разрешайте конфликты вручную:

```bash
git apply --3way ../khadamni-fixes.patch
```

## Что нужно сделать руками при выкатке

1. **Миграция БД.** Патч добавляет в `schema.sql` два блока:
   `ALTER TABLE users ADD COLUMN token_version` и таблицу `admin_audit`.
   Прогоните `npm run migrate` до раскатки нового бэкенда.

2. **`NEXT_PUBLIC_API_URL` теперь обязателен на сборке веба.** Фолбэк на
   боевой IP убран специально — без переменной сборка падает с внятной
   ошибкой. Проверьте, что переменная задана в пайплайне сборки и в
   `deploy/k8s`.

3. **Минимальная длина пароля выросла с 6 до 8.** Существующие пароли
   продолжают работать — правило действует только на регистрацию и сброс.

4. **Проверьте `S3_PUBLIC_URL`.** Если он задан, до этого патча резюме
   соискателей отдавались через публичный CDN. Ссылки на такие файлы могли
   осесть в кэшах и логах CDN — стоит инвалидировать кэш по префиксу
   документов.

## Что НЕ входит в патч

- **Замена растровых иконок категорий на вектор** — вынесена по вашей
  просьбе. Пока она не сделана, тёмная тема продолжает светиться:
  `tileBg` в тёмной теме остаётся светлым бежем именно ради этих PNG.
- **Единая шкала типографики (D3).** Структурно поправить недостаточно:
  свести `font` к `type` — значит поменять кегль заголовков на всех
  экранах (h1 32 → 26, h2 26 → 21). Это визуальный редизайн, а не
  исправление бага, и вслепую, без прогона приложения на устройстве,
  делать его неправильно.
- **Очередь уведомлений (A2), батч-загрузчики (A1), пагинация (A3).**
  Требуют новой зависимости и воркера в кластере (A2) либо согласованных
  правок клиентов (A3). Это отдельная задача с деплоем, а не правка кода.
- **Ограничение масштабирования шрифта 130% (D12).** Снимается только
  вместе с переводом контролов с фиксированной высоты на `minHeight` —
  тоже визуальная правка, которую надо смотреть на устройстве.
