# Веб-клиент «Маяка»

Интерфейс перенесён из присланного образца (Tito): тёмная бирюзовая тема,
боковая панель со списком чатов рядом с перепиской, живой перевод.

Данные — настоящие. В образце переписка лежала в `localStorage` из файла с
выдуманными людьми; здесь всё идёт через наш Go-сервер: вход по номеру
телефона, доставка сокетом, докачка после обрыва.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
```

Сервер должен быть поднят (`make up && make run` в корне) и знать про адрес
клиента:

```sh
MAYAK_CORS_ORIGINS=http://localhost:5173 make run
```

Адрес API задаётся на сборке: `VITE_API_BASE=https://api.example.com npm run build`.
По умолчанию — `http://localhost:8080`.

## Что откуда

| Из образца | Наше |
|---|---|
| `styles.css` — палитра, радиусы, тени | `lib/api.ts` — REST |
| `components/*` — панель, переписка, лента, поле ввода | `lib/ws.ts` — сокет, переподключение |
| `lib/i18n.ts`, `lib/format.ts` | `lib/store.ts` — состояние поверх сервера |
| `components/ui/*` на Radix | `components/sign-in.tsx` — вход по номеру |

Выброшено: `better-auth`, PGlite, Nitro и пресет Vercel, серверный рендеринг
и выдуманные данные. Приложение целиком за входом и живёт на сокете —
отдавать его сервером нечего.

## Шрифты

Manrope и Unbounded лежат в `public/fonts`, а не тянутся с
`fonts.gstatic.com`: до Google из России доходит не всегда, а со шрифтом на
чужом домене первый экран показывается системным начертанием и потом
перерисовывается — если домен вообще ответит. Оставлены кириллица и
латиница, остальные подмножества выброшены.

## Перевод

Тумблер «живой перевод» в шапке чата и кнопка «оригинал» на сообщении
работают, но поставщика перевода на сервере пока нет: `/v1/ai/translate`
отвечает `503 translate_not_configured`, и клиент говорит об этом словами.
Подключение поставщика — один файл в `server/internal/translate`.
